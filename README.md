# 🎭 Pesquisa Culturama

> Uma plataforma/ferramenta focada na pesquisa, organização e exploração de conteúdos culturais de forma interativa e acessível.

## 🚀 Sobre o Projeto
O **Pesquisa Culturama** foi desenvolvido para centralizar dados e pesquisas do universo cultural, proporcionando aos utilizadores uma experiência prática na busca por informações, referências ou catálogos culturais.

## ✨ Funcionalidades
- **Sistema de Pesquisa:** Ferramenta para localizar conteúdos e dados culturais rapidamente.
- **Organização de Dados:** Estruturação limpa de informações para facilitar a visualização.
- **Interface Intuitiva:** Design focado na facilidade de uso e boa experiência do utilizador (UX).

## 🛠️ Tecnologias Utilizadas
- **HTML5, CSS3
